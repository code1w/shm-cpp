# RAII 注册句柄：验证与前后性能检查

基线为提交 a925904；候选为本次未提交实现。均为Release -O3 -DNDEBUG，CPU1服务端、CPU3客户端，NUMA1；CPU2/4七天稳定性测试保持运行。

五个固定尺寸/batch配置×eventfd/busy两模式×前后版本×三轮，共60次运行；每次预热1秒、测量5秒，版本顺序交错。消息序号、内容、批次数和fd/mapping回收均经既有benchmark校验。

表内RPC/s和P50分别为三轮中位数；吞吐变化为逐轮配对比值的中位数，因此不能直接用表内两个独立中位数代算。短测与三轮波动不是置信区间。

各配置配对吞吐变化为−1.82%～+1.90%，本轮未观察到明显性能回归；不将这类小差异视为稳定性能收益。详细范围和逐轮数据见 performance/summary.json、performance/samples.json。

新增测试覆盖注册身份、句柄移动/替换、借用fd所有权、nothrow分配失败、同批次取消、回调内替换、fd和timerfd复用、周期/一次性定时器、busy错误返回以及服务端/客户端两项注册失败后的恢复。Release及ASan/UBSan验证通过。

四进程Protobuf ASan/UBSan收发冒烟覆盖16B、4KiB、1MiB及三种已有传输模式，共15个配置，固定257 RPC；全部通过共享内存直接编码、计数、内容和fd恢复检查。sanitizer_chain 的吞吐数字不用于性能比较。

新增代码与测试未引入try/catch/throw语句。普通fd和busy数据回调直接存储可调用对象，注册时一次nothrow分配；数据编解码、SPSC环和通知协议没有改变。

后续变更：busy 循环的 CPU pause/yield 提示指令已按要求删除。上述性能表及 source_snapshot 保留删除前的测量版本，不代表删除后的性能结果。
