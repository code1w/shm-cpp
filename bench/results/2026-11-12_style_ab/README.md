# 风格重构 A/B 基准（2026-11-12）

对比 e039929（重构前）与 79ba2f2（重构后），Release `-O3`（两侧相同），
`bench.sh -r 3`（server 核 2 / client 核 4），4 轮交错运行，原始输出见 `o3_same_flags/`。

SHM MB/s（每轮为 3 轮中位数）：

| 载荷 | 重构前 | 重构后 |
|---|---|---|
| 64B | 2017–2380 | 1888–2066 |
| 512B | 10969–12506 | 9943–12699 |
| 4KB | 18614–19649 | 17997–19961 |
| 64KB | 22609–22916 | 22470–22911 |

结论：无可确认的退化。e039929..183ea64 的 server/client `.text` 字节级一致；
79ba2f2 仅改动握手路径。512B 档存在双峰噪声，两侧范围大幅重叠。

注：首次 A/B 曾因基线 worktree 为 -O3 而主 build 为 -O2 得出假退化，数据已废弃。
